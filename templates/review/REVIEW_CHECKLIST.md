# Agent Review Checklist

## Correctness

- [ ] Does the code satisfy the spec?
- [ ] Are edge cases handled?
- [ ] Are failures explicit?

## Architecture

- [ ] Does this preserve ownership boundaries?
- [ ] Is policy enforced in code, not only prompts?
- [ ] Is shared logic placed deliberately?

## Tests

- [ ] Are meaningful tests added or updated?
- [ ] Would the previous bug fail before the fix?

## Docs

- [ ] Do specs/docs/plans need updates?
- [ ] Are durable lessons promoted?
